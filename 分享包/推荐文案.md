推荐个自己部署的小工具 —— **抖音自动续火花**：

不用天天惦记着火花了，它会按你设的时间自动给好友发消息续火花。比较自然的是它**每天第一次发一条早安晨报**（早上好 + 5 条热点新闻 + 按好友城市查的天气 + 一句名言），之后可以给它点一下「转发热门视频」，从你点过赞的喜欢和抖音热点榜里按类型挑视频转过去（美食/旅游/宠物/拍照），会话里就是正常的视频分享卡片。

自带网页配置，点点就行，Docker 一条命令起：

```
docker run -d --name douyin-auto-fire --restart unless-stopped \
  -p 8600:8600 -v "$PWD/data:/data" \
  -e WEB_PASSWORD=自己设个密码 caowenrui/douyin-auto-fire:latest
```

然后浏览器打开 http://服务器IP:8600 就行。

项目地址：https://github.com/Caoran1314/douyin-auto-fire
镜像地址：https://hub.docker.com/r/caowenrui/douyin-auto-fire
（仅供学习自用，账号风险自负哈）

【版本二 · 技术版】适合发给懂 Docker 的人
════════════════════════════════════════

抖音自动续火花 · Docker 版（自带配置网页）
GitHub：https://github.com/Caoran1314/douyin-auto-fire
Docker Hub：https://hub.docker.com/r/caowenrui/douyin-auto-fire

一条命令跑起来（镜像 611MB，内含 Chromium，amd64）：

```bash
mkdir -p douyin-auto-fire/data && cd douyin-auto-fire
echo "WEB_PASSWORD=你设的密码" > .env
curl -O https://raw.githubusercontent.com/Caoran1314/douyin-auto-fire/main/docker-compose.hub.yml
mv docker-compose.hub.yml docker-compose.yml && docker compose up -d
```

或者用 docker run：

```bash
docker run -d --name douyin-auto-fire --restart unless-stopped \
  -p 8600:8600 -v "$PWD/data:/data" \
  -e WEB_PASSWORD=你设的密码 -e TZ=Asia/Shanghai \
  caowenrui/douyin-auto-fire:latest
```

用法：打开 http://服务器IP:8600（用 WEB_PASSWORD 登录）→ 粘抖音 Cookie（Cookie-Editor 导出 JSON）→
「扫描私信列表」→ 导入好友 → 给每人选个城市 → 保存。之后每天 08:00 自动发晨报，
手动点「只转发视频」就转发热门视频。配置、Cookie、日志都在 ./data，备份它就够了。

要点：
- 容器内自带调度器，不用 systemd/cron；重启策略 unless-stopped 会自启
- 发视频走的是抖音「分享 → 分享给朋友」，不需要额外权限；不在互关列表里的好友会自动改发文字
- 想改代码：git clone 后 `docker compose up -d --build`
